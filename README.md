# TU ClassFlow

TU ClassFlow is a cloud-based Learning Management System (LMS)
developed for managing courses, assignments, submissions,
grading, and notifications between instructors and students.

---

# Features

- User Authentication
- Course Enrollment
- Assignment Management
- Assignment Submission
- File Upload & Download
- Feedback & Grading
- Deadline Notification
- Dynamic Dashboard

---

# Technologies Used

## Frontend
- HTML
- CSS
- JavaScript

## Backend
- Spring Boot
- REST API
- JPA / Hibernate

## Cloud Services
- Amazon Cognito
- Amazon RDS
- Amazon S3
- Amazon SNS
- Amazon EventBridge

---

# System Architecture

Frontend
↓
Spring Boot Backend
↓
Amazon RDS + Amazon S3 + SNS + Cognito

---

# AWS Services Used

| Service | Purpose |
|---|---|
| Amazon Cognito | Authentication |
| Amazon RDS | Database |
| Amazon S3 | File Storage |
| Amazon SNS | Email Notification |
| Amazon EventBridge | Deadline Trigger |

---

# Setup Instructions

## Backend

1. Open backend project
2. Configure application.properties
3. Run Spring Boot application

## Frontend

1. Open HTML pages
2. Run using Live Server
